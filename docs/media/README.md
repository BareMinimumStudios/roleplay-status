# Project page media

- `dice-shapes.png`: labeled renderer geometry preview of the supported die types.
- `dice-animation.gif`: illustrative HUD animation generated from the renderer geometry, not captured gameplay.

`MODRINTH.md` is the copy-ready Modrinth description. Its image URLs use the public
`main` branch; commit and push these assets before pasting the description into Modrinth.
Publishing a new mod version does not update the project description automatically.

User-provided actual Minecraft screenshots, preserved unchanged:

- `tab-standard-original.png`: normal indicators with colorblind mode and status labels off.
- `tab-colorblind-ooc-original.png`: Out of Character outline with colorblind mode and labels on.
- `tab-colorblind-open-rp-original.png`: Open to RP plus shape with colorblind mode and labels on.

`tab-accessibility-comparison.png` is an AI-assisted presentation layout based on
these captures, with matching panel styles and explanatory headings. It is not a
pixel-identical substitute for the source screenshots. The page links all unedited
captures alongside the designed comparison so the actual game output is available.
